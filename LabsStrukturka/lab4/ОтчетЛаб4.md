### Базовая задача: Необходимо реализовать программу, которая анализирует текст и считает, сколько раз встречается каждое слово.
### Вариативная часть:

 - Выводить только слова, которые встретились больше одного раза

### Основная работа программы:

- Чтение строки или текста
- Разбиение текста на слова
- Подсчёт количества повторений каждого слова
- Вывод результата в формате слово -> количество

## Реализация

### Принятие текста и возвращение словаря с частотой каждого слова
```python
def count_word_frequencies(text):
    text = text.lower()
    words = text.split()

    frequency = {}

    for word in words:
        if word in frequency:
            frequency[word] += 1
        else:
            frequency[word] = 1

    return frequency
```
### Принятие словаря с частотами и вывод только повторяющегося слова

```python
def print_results(frequency):
    for word, count in frequency.items():
        if count > 1:
            print(f"{word} -> {count}")
```
