### Основная работа программы:

 - Программа реализует очередь"FIFO" с использованием двух стеков. В отличие от обычной очереди на списке, данная реализация оптимизирована для быстрых операций добавления и извлечения элементов.

 - Принцип работы очереди на двух стеках:

 - Элементы добавляются во входной стек (stack_in)

 - При извлечении элемента, если выходной стек (stack_out) пуст, все элементы из входного стека переносятся в выходной (при этом порядок элементов меняется на противоположный)

 - После этого элемент извлекается из выходного стека, что соответствует порядку очереди

## Блок подключения библиотек и реализация

### Добавление элемента в конец очереди
```python
def enqueue(self, x):
	self.stack_in.append(x)
```
### Переносит элементы из входного стека в выходной

```python
def _transfer(self):
	if not self.stack_out:
		while self.stack_in:
			self.stack_out.append(self.stack_in.pop())
```

### Удаление и возвращение первого элемента из очереди

```python
def dequeue(self):
	if self.is_empty():
		raise IndexError("Очередь пуста")
	self._transfer()
	return self.stack_out.pop()
```
### Возвращение первого элемента без удаления

```python
def front(self):
	if self.is_empty():
		raise IndexError("Очередь пуста")
	self._transfer()
	return self.stack_out[-1]
```

### Возвращение количества элементов в очереди

```python
def size(self):
	return len(self.stack_in) + len(self.stack_out)
```
### Проверка на пустоту

```python
def is_empty(self):
	return self.size() == 0
```

### Отчистка стэков

```python
def clear(self):
	self.stack_in.clear()
	self.stack_out.clear()
```
### Вывод содержимого на экран
```python
def display(self):
	if self.is_empty():
		print("Очередь пуста")
	return
	self._transfer()
	print("Очередь:", self.stack_out[::-1] + self.stack_in)
```
